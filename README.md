# Hotel Management System

An academic mini-project demonstrating a hotel room booking and payment workflow using Spring Boot and Thymeleaf.

## Features

- Room booking interface
- Payment simulation
- Booking confirmation workflow

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- HTML5
- CSS3
- Maven

## Workflow

Home → Booking → Payment → Thank You

## Repository Contents

- Project documentation (`.docx`)
- System design
- ER diagram
- Implementation details
- Future enhancement ideas

This repository currently contains the project documentation. The source code implementation is being reconstructed and will be added soon.
